# Yo‘lchiyev Rustam — loyiha taqdimoti

[PowerPoint faylini ochish](Yolchiyev_Rustam_Loyiha_Taqdimoti_25_slayd.pptx). GitHub sahifasidagi **Download raw** tugmasi orqali yuklab oling.

Foydalanuvchi bergan 25 slaydli taqdimotning ranglari, Aptos shrifti va asosiy tuzilishi saqlandi. Universitet baholariga oid misollar kompaniya PC’lari ssenariysiga moslashtirildi. Jadvallar va matnlar PowerPoint’da tahrirlanadi.

Asosiy qo‘llanish doirasi kompaniyalarning turli bo‘lim va tarmoqlaridagi ko‘p sonli PC’larni markazdan boshqarish. Rahbar ma’lumoti uchun joy bo‘sh qoldirilgan.

## Ekran rasmlari va cheklovlar

8 ta ekran rasmi mahalliy Django serverida vaqtinchalik namuna kompaniyasi bilan olingan. Mobil ko‘rinish brauzerda ochilgan. PC ma’lumotlari namuna sifatida yuborilgan, QR va tasdiqlash kodlari amaldan chiqarilgan. Ekranlar fizik telefon sensori yoki native Windows o‘rnatish sinovi bajarilganini anglatmaydi.

Windows o‘rnatuvchisining haqiqiy oynalari hali kiritilmagan. Agent aktivatsiyasi manba kodiga tayangan holda tushuntirilgan. Majburiy MFA ketma-ketligi, Windows kirish oynasi bilan to‘liq integratsiya, biometrik tiriklik tekshiruvi va korporativ yuklama keyingi tekshiruvlar sifatida ko‘rsatilgan.

Slaydlardagi test natijalari avval qayd etilgan mahalliy tekshiruvlarga tegishli. Taqdimot tahririda dastur testlari qayta bajarilgani da’vo qilinmaydi. Nazariy manbalar va loyiha kodi havolalari tegishli slayd izohlarida ham mavjud.
